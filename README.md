# How do i build ts 

the original thing was made by https://github.com/ludovic111 give him a visit for the original stuff :)

so how to build it, or just go get it from the releases if you just wanna play.

step 1: breathe.

step 1.5: Get Windows SDK and Cargo/rust on your device

step 2: get your file to somewhere you know and is easy to locate.

step 2.5: unzip the thing

step 3: open cmd and run these:

- cd \path\path\path\HorizonLauncher-Cracked-main.zip (could be longer depending on where it is)
- cd launcher
- cargo build --release

step 4: go to \launcher\target\release\ and you will have your .exe there. Enjoy!
